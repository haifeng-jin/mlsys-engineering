9.3. Common data types

Even within floating-point types alone, there are many different formats. You have probably heard of FP32, BF16, and FP64. They all follow the same three-part structure (sign, exponent, and mantissa), but they differ in their total number of bits and how they divide those bits between the exponent and the mantissa. More bits for the exponent give a wider range of representable numbers, while more bits for the mantissa provide higher precision.

Formats are often described using the shorthand ExMy, where x is the number of exponent bits and y is the number of mantissa bits. For example, E4M3 uses 4 bits for the exponent and 3 bits for the mantissa, with 1 sign bit giving 8 bits in total, as shown in the figure below.

Figure 39. E4M3 format.

Similarly, BF16 is E8M7. FP16, which is also 16 bits total, is E5M10. It trades exponent range for mantissa precision, making it more likely to overflow at large values and to underflow to zero at small values. The table below shows the bit layout for the most common floating-point formats in ML.

Table 2. Bit layout of common floating-point formats.
Format Total bits Sign Exponent Mantissa
FP64 64 1 11 52
FP32 32 1 8 23
BF16 16 1 8 7
FP16 16 1 5 10
FP8 (E4M3) 8 1 4 3
FP8 (E5M2) 8 1 5 2
FP4 (E2M1) 4 1 2 1

While neural network weights and activations are typically represented as floating-point numbers, machine learning systems also rely on a few other data types:

  • Integers: Integers represent whole numbers with no fractional component, such as -1, 0, or 42.
  • Booleans: Booleans represent binary truth values: either True or False.
  • Complex numbers: Complex numbers have the form a + bi, where a and b are floating-point numbers representing the real and imaginary parts, and i = .

The table below summarizes these data types along with their bit widths and representable ranges.

Table 3. Other common data types in machine learning.
Category Format Bits Range
Integer INT4 4 -8 to 7
Integer INT8 8 -128 to 127
Integer UINT8 8 0 to 255
Integer INT32 32 -231 to 231-1
Integer INT64 64 -263 to 263-1
Boolean BOOL 8 0 or 1 (False or True)
Complex COMPLEX64 64 Two FP32 numbers
Complex COMPLEX128 128 Two FP64 numbers

You may be curious how 4-bit formats work because 4 bits is not even a full byte. Memory is addressed byte by byte, so numbers like INT4 and FP4 are packed two per byte. Some recent hardware can compute on 4-bit numbers directly. Otherwise, they are unpacked into a wider format before computation.
