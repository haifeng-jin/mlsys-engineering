10.5. Activation checkpointing

As we saw in autodiff, the backward pass needs the saved activations from the forward pass. For deep models, holding all these activations in GPU memory takes up substantial space and frequently causes out-of-memory errors.

To reduce memory usage, we can trade compute for memory using activation checkpointing. Instead of saving intermediate activations at every op, we only keep them at selected points along the chain, as shown below.

Figure 51. Checkpointed forward pass.

This drastically reduces the amount of memory needed to store activations during training.

However, when the backward pass reaches an op whose input activation was not saved, such as op2 needing x1, the framework must recompute it on the fly. It does this by running op1 forward again starting from the nearest saved checkpoint x0, as shown below.

Figure 52. Checkpointed backward pass.

Activation checkpointing is essentially trading compute for more memory space: rerunning forward ops consumes additional compute cycles, but in return, it frees up substantial GPU memory.

Recomputing compute-heavy operations adds significant overhead, while recomputing cheap operations costs very little extra time. In practice, users can select which layers to checkpoint, and modern compilers can even automate this choice to balance memory savings against runtime overhead.1

Throughout this chapter, we have seen how frameworks translate high-level Python code into execution on hardware, chaining forward and backward passes together and managing activation memory through checkpointing. However, simply executing operations one after another leaves significant performance on the table. In the next chapter, we look at deep learning compilers, exploring how they analyze the model as a whole to further optimize execution on hardware.

1. Compilers can automate this selection across arbitrary computation graphs using graph partitioning algorithms such as min-cut, weighting the cut to avoid recomputing compute-heavy operations while minimizing saved memory.
